# robosuite 使用说明文档

## 简介

**robosuite** 是由斯坦福大学 ARISE Lab 开源的机器人操控仿真框架，基于 MuJoCo 物理引擎构建。它提供了多款真实机械臂模型、多种操控任务环境、多种控制器实现，并与 Gymnasium（OpenAI Gym）接口兼容，广泛应用于机器人学习研究领域。

**GitHub**：https://github.com/ARISE-Initiative/robosuite

---

## 环境要求

- Python 3.8+
- MuJoCo 2.3.0+（已安装 MuJoCo 3.10.0 可直接使用）
- pip

---

## 安装

### 方式一：pip 安装（推荐）

```bash
pip install robosuite
```

### 方式二：从本地源码安装（本仓库已克隆）

```bash
cd robosuite/
pip install -e .
```

### 安装可选依赖

```bash
# 用于强化学习训练
pip install stable-baselines3 gymnasium

# 用于可视化录制
pip install imageio imageio-ffmpeg

# 用于 USD 导出（3D场景）
pip install usd-core
```

| 控制器名 | 控制空间 | 输入维度 | 推荐场景 |
|---------|---------|---------|---------|
| `OSC_POSE` | 末端位姿（位置+姿态） | 6 + 1(夹爪) | **抓取任务首选** |
| `OSC_POSITION` | 末端位置 | 3 + 1(夹爪) | 简单移动 |
| `IK_POSE` | 逆运动学位姿 | 6 + 1(夹爪) | 精确位置控制 |

| `JOINT_VELOCITY` | 关节速度 | N + 1(夹爪) | 速度控制 |
| `JOINT_TORQUE` | 关节力矩 | N + 1(夹爪) | 力控研究 |

## Python API 使用示例

### 1. 最简单：随机动作仿真

```python
import robosuite as suite
import numpy as np

# 创建 Lift（举起方块）环境，使用 Panda 机械臂
env = suite.make(
    env_name="Lift",
    robots="Panda",
    has_renderer=True,           # 开启可视化窗口
    has_offscreen_renderer=False,
    use_camera_obs=False,
    control_freq=20,
)

obs = env.reset()

for i in range(1000):
    action = np.random.randn(*env.action_spec[0].shape)
    obs, reward, done, info = env.step(action)
    env.render()
    if done:
        obs = env.reset()

env.close()
```

### 2. 机械臂抓取仿真（OSC 控制器）

```python
import robosuite as suite
import numpy as np

# 创建 PickPlace 环境，使用 OSC 操作空间控制器
env = suite.make(
    env_name="PickPlace",
    robots="Panda",
    controller_configs=suite.load_controller_config(default_controller="OSC_POSE"),
    has_renderer=True,
    has_offscreen_renderer=False,
    use_camera_obs=False,
    reward_shaping=True,         # 密集奖励，利于 RL 训练
    control_freq=20,
)

obs = env.reset()
print("观测维度:", obs["robot0_eef_pos"].shape)  # 末端位置
print("动作空间:", env.action_spec)

for i in range(500):
    # action = [dx, dy, dz, droll, dpitch, dyaw, gripper]
    # gripper: -1=张开, 1=关闭
    action = np.zeros(7)
    action[2] = -0.05   # 向下移动
    action[6] = 1.0     # 关闭夹爪

    obs, reward, done, info = env.step(action)
    env.render()

env.close()
```

### 3. 获取相机图像观测

```python
import robosuite as suite

env = suite.make(
    env_name="Lift",
    robots="Panda",
    has_renderer=False,
    has_offscreen_renderer=True,   # 必须开启离屏渲染
    use_camera_obs=True,           # 开启相机观测
    camera_names=["frontview", "birdview", "agentview", "robot0_eye_in_hand"],
    camera_heights=84,
    camera_widths=84,
    control_freq=20,
)

obs = env.reset()
# 访问相机图像
front_img = obs["frontview_image"]    # shape: (84, 84, 3)
wrist_img = obs["robot0_eye_in_hand_image"]  # 腕部相机

import imageio
imageio.imwrite("front_view.png", front_img)
```

### 4. 与 Gymnasium 接口集成（用于 RL 训练）

```python
import robosuite as suite
from robosuite.wrappers import GymWrapper
import numpy as np

# 创建环境并包装为 Gym 接口
env = GymWrapper(
    suite.make(
        env_name="Lift",
        robots="Panda",
        controller_configs=suite.load_controller_config(default_controller="OSC_POSE"),
        has_renderer=False,
        has_offscreen_renderer=False,
        use_camera_obs=False,
        reward_shaping=True,
        control_freq=20,
    )
)

# 现在可以像标准 Gym 环境一样使用
obs, info = env.reset()
print("观测空间:", env.observation_space)
print("动作空间:", env.action_space)

for _ in range(100):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()
```

### 5. 使用 Stable-Baselines3 训练 RL 策略

```python
import robosuite as suite
from robosuite.wrappers import GymWrapper
from stable_baselines3 import SAC
from stable_baselines3.common.env_checker import check_env

# 创建环境
env = GymWrapper(
    suite.make(
        env_name="Lift",
        robots="Panda",
        controller_configs=suite.load_controller_config(default_controller="OSC_POSE"),
        has_renderer=False,
        has_offscreen_renderer=False,
        use_camera_obs=False,
        reward_shaping=True,
        control_freq=20,
        horizon=500,
    )
)

# 训练 SAC 智能体
model = SAC("MlpPolicy", env, verbose=1, tensorboard_log="./logs/")
model.learn(total_timesteps=100_000)
model.save("panda_lift_sac")

# 加载并测试
model = SAC.load("panda_lift_sac")
obs, _ = env.reset()
for _ in range(500):
    action, _ = model.predict(obs)
    obs, reward, done, _, _ = env.step(action)
    if done:
        obs, _ = env.reset()
```

## 观测空间说明

默认观测包含以下键值：

| 观测键 | 含义 | 维度 |
|--------|------|------|
| `robot0_joint_pos` | 关节角度 | (7,) |
| `robot0_joint_vel` | 关节速度 | (7,) |
| `robot0_eef_pos` | 末端位置 (x,y,z) | (3,) |
| `robot0_eef_quat` | 末端姿态（四元数）| (4,) |
| `robot0_gripper_qpos` | 夹爪关节角度 | (2,) |
| `robot0_eye_in_hand_image` | 腕部相机图像 | (H,W,3) |
| `frontview_image` | 前视相机图像 | (H,W,3) |
| `object-state` | 物体位置/速度信息 | 可变 |

## 奖励函数说明

| 任务 | 稀疏奖励 | 密集奖励（`reward_shaping=True`）|
|------|---------|--------------------------------|
| **Lift** | 举起方块得 2.25 | 接近+抓握+举起分段奖励 |
| **PickPlace** | 放到目标区得 1.0 | 接近+抓取+搬运分段奖励 |
| **Stack** | 堆叠成功得 1.0 | 多阶段密集奖励 |
| **Door** | 开门成功得 1.0 | 接近把手+旋转+推开奖励 |

## 常见问题

**Q: 导入 robosuite 报 `ModuleNotFoundError`**
```bash
pip install robosuite
# 或从本地安装
cd robosuite/ && pip install -e .
```

**Q: 渲染窗口无法显示（libGL 错误）**
```bash
sudo apt-get install libgl1-mesa-glx libglu1-mesa
export LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libGL.so.1
```

**Q: 训练速度慢**
- 关闭 `has_renderer=False` 和 `has_offscreen_renderer=False`（不需要图像时）
- 使用 `control_freq=10`（降低控制频率）
- 使用向量化环境：`stable_baselines3.common.vec_env.SubprocVecEnv`

**Q: 如何使用本仓库 `models/menagerie/` 中的机械臂模型**
- robosuite 自带的机械臂模型已足够使用
- 如需自定义，参考 `robosuite/models/robots/` 中的机器人定义方式，仿照 menagerie 的 MJCF 文件接入
