# robosuite 使用说明文档

## 简介

**robosuite** 是由斯坦福大学 ARISE Lab 开源的机器人操控仿真框架，基于 MuJoCo 物理引擎构建。它提供了多款真实机械臂模型、多种操控任务环境、多种控制器实现，并与 Gymnasium（OpenAI Gym）接口兼容，广泛应用于机器人学习研究领域。

**GitHub**：https://github.com/ARISE-Initiative/robosuite

---

## 环境要求

- Python 3.8+
- MuJoCo 2.3.0+（已安装 MuJoCo 3.10.0 可直接使用）
- pip

---

## 安装

### 方式一：pip 安装（推荐）

```bash
pip install robosuite
```

### 方式二：从本地源码安装（本仓库已克隆）

```bash
cd robosuite/
pip install -e .
```

### 安装可选依赖

```bash
# 用于强化学习训练
pip install stable-baselines3 gymnasium

# 用于可视化录制
pip install imageio imageio-ffmpeg

# 用于 USD 导出（3D场景）
pip install usd-core
```

### ⭐ 新增：脚本化抓取+放置（基于坐标，无需 RL）

| Demo 文件 | 一句话功能 | 适合场景 |
|-----------|-----------|---------|  
| **`demo_grasp_scripted`** | 读取方块坐标 → 全自动完成**抓取+搬运+放置**，支持独立夹爪选择、视频录制，以及 **RRT 自动路径规划** | 机械臂抓取仿真最直接起点；`--plan` 模式可自动绕障规划路径 |

```bash
# 默认模式（固定 6 阶段运动序列）
python -m robosuite.demos.demo_grasp_scripted

# RRT 路径规划模式（自动求解运动路径）
python -m robosuite.demos.demo_grasp_scripted --plan

# 完整示例
python -m robosuite.demos.demo_grasp_scripted \
    --robot UR5e --gripper Robotiq85Gripper \
    --place-pos 0.15 0.15 0.82 \
    --plan --save-video output.mp4
```

**全部参数**：

| 参数 | 说明 | 示例 |
|------|------|------|
| `--robot` | 机械臂型号 | `Panda`/`UR5e`/`IIWA`/`xArm7` |
| `--gripper` | **独立**选择夹爪 | `Robotiq85Gripper`/`PandaGripper`/`default` |
| `--place-pos X Y Z` | 放置目标坐标（桌面约 z=0.82） | `0.15 0.15 0.82` |
| `--plan` | **启用 RRT 路径规划**（自动避障，替代固定运动序列） | 无需值，加上即生效 |
| `--plan-step` | RRT 步长（m），越小越精细但更慢 | `0.07`（默认） |
| `--plan-iter` | RRT 最大迭代次数 | `3000`（默认） |
| `--save-video PATH` | 保存执行过程为 mp4 | `output.mp4` |
| `--camera` | 录制相机（默认 agentview） | `frontview`/`birdview` |
| `--nreset` | 重复次数 | `3` |
| `--speed` | 速度缩放 | `1.0`/`1.5` |

**两种运动模式对比**：

| 模式 | 触发方式 | 原理 | 适用场景 |
|------|---------|------|---------|
| **固定 6 阶段**（默认）| 不加 `--plan` | 预设提起→水平移动→放下的固定路径 | 简单桌面任务，速度快 |
| **RRT 路径规划** | 加 `--plan` | 在工作空间内自动搜索无碰撞路径，路径点间距 `step_size`，支持平滑处理 | 需要自动避障，或终点位置不确定时 |

**RRT 规划器工作原理**：
```
1. 直线检测：若起点→终点直线路径无碰撞，直接返回（无需迭代）
2. RRT 迭代：随机采样工作空间（20%概率直接采样目标）→ 找最近节点 → 延伸一步
3. 碰撞检测：检查新节点是否在桌面以上 + 工作空间范围内
4. 路径平滑：找到路径后贪心跳过不必要的中间节点
5. 失败退化：超过迭代次数时退化为直线路径
```

### 第一类：看效果 / 快速上手

| Demo 文件 | 一句话功能 | 适合场景 |
|-----------|-----------|---------|
| **`demo_random_action`** | 选一个任务 + 选一个机械臂 → 机械臂在环境中乱动 | **最适合第一次运行**，验证安装是否正常，直观看到仿真效果 |
| **`demo_multi_camera`** | 与随机动作相同，但**同时显示多个视角**（正视图+鸟瞰图等） | 想了解场景里有哪些相机、画面效果如何 |
| **`demo_renderers`** | 切换不同渲染后端（mujoco / mjviewer），后者有**交互控制面板** | 探索渲染器快捷键，如线框模式、碰撞点显示等 |

### 第四类：记录和保存数据

| Demo 文件 | 一句话功能 | 适合场景 |
|-----------|-----------|---------|
| **`demo_video_recording`** | 运行仿真并**保存为 mp4 视频**（无窗口，离屏渲染） | 想截图或录视频展示仿真效果，或在无显示器的服务器上运行 |

| **`demo_usd_export`** | 遥操作机械臂，同时将轨迹导出为 **USD 格式** 供 Blender/Omniverse 高质量渲染 | 需要制作论文配图或宣传视频的高质量渲染 |

### 第五类：环境包装器（高级功能）

| Demo 文件 | 一句话功能 | 适合场景 |
|-----------|-----------|---------|
| **`demo_gym_functionality`** | 将 robosuite 环境**包装为标准 Gymnasium 接口**（reset/step 格式统一） | 想用 Stable-Baselines3 / CleanRL 等 RL 库直接训练 |
| **`demo_domain_randomization`** | 每次 reset 时**随机改变场景外观**（纹理/光照/相机/物理参数） | Sim-to-Real 研究：让策略在真实机器人上也能工作 |
| **`demo_sensor_corruption`** | 给传感器观测值加**高斯噪声和延迟**，遥操作时能实时感受到影响 | 测试控制算法对传感器误差的鲁棒性 |
| **`demo_composite_robot`** | **动态拼装机器人**：用命令行指定机械臂型号+底座+夹爪自由组合 | 测试新的机器人配置，不需要修改任何 XML 文件 |

### 三、相机视角

#### 场景固定相机（所有任务均可用）

| 相机名称 | 位置描述 | 视角特点 | 推荐用途 |
|---------|---------|---------|---------|
| `agentview` | 正前方斜下 45° | **最全面视角**，可同时看到机械臂和桌面 | ✅ **默认推荐**，适合大多数任务观察和录制 |
| `frontview` | 正前方平视 | 接近人眼观察角度，桌面细节清晰 | ✅ 推荐用于展示/录制，默认渲染窗口视角 |
| `birdview` | 正上方俯视 | 完整俯视桌面，看路径规划轨迹直观 | ✅ 推荐用于路径规划可视化 |
| `sideview` | 右侧 90° 侧视 | 观察机械臂垂直方向运动（抓取高度） | 适合调试下降/提升阶段 |

#### 机器人随动相机

| 相机名称 | 位置描述 | 视角特点 | 推荐用途 |
|---------|---------|---------|---------|
| `robot0_eye_in_hand` | 末端执行器腕部 | **跟随末端运动**，FoV=75°，抓取时方块居中 | ✅ 强烈推荐用于**抓取仿真录制**，直观展示抓取过程 |
| `robot0_robotview` | 机器人底座视角 | 固定在机器人底座，跟随但不随末端移动 | 较少使用 |

#### 相机使用方式

```python
# 视频录制时指定相机（demo_grasp_scripted --save-video）
python -m robosuite.demos.demo_grasp_scripted --save-video demo.mp4 --camera agentview

# 同时使用多个相机（demo_multi_camera）
python -m robosuite.demos.demo_multi_camera
# 在代码中设置：env.viewer.set_camera(camera_name=["agentview", "birdview"])

# Python API 中获取相机图像
env = suite.make(
    "Lift", robots="Panda",
    has_offscreen_renderer=True,
    use_camera_obs=True,
    camera_names=["agentview", "robot0_eye_in_hand"],  # 同时启用多个
    camera_heights=480, camera_widths=640,
)
obs = env.reset()
front_img  = obs["agentview_image"]           # shape: (480, 640, 3)
wrist_img  = obs["robot0_eye_in_hand_image"]  # 腕部相机图像
```

#### 推荐相机组合

| 使用目的 | 推荐相机 | 说明 |
|---------|---------|------|
| **抓取任务观察** | `agentview` | 视野全面，机械臂和目标物体都可见 |
| **展示/发布视频** | `frontview` | 画面最美观，接近人眼视角 |
| **路径规划调试** | `birdview` | 俯视全局，轨迹一目了然 |
| **抓取细节录制** | `robot0_eye_in_hand` | 跟随末端，能看到夹爪抓取瞬间 |
| **论文/汇报多视角** | `agentview` + `robot0_eye_in_hand` | 宏观+微观双视角同时录制 |

**核心控制逻辑**（比例控制，无需 RL）：

```python
# 每步计算：误差 → clip 到最大步长 → 发送给 OSC 控制器
error = target_pos - obs["robot0_eef_pos"]          # 目标 - 当前
delta = np.clip(error, -MAX_STEP, MAX_STEP)          # 限制步长
action = [delta[0], delta[1], delta[2], 0, 0, 0, gripper]  # OSC_POSE 格式
obs, reward, done, _ = env.step(action)
```

## Python API 使用示例

### 1. 最简单：随机动作仿真

```python
import robosuite as suite
import numpy as np

# 创建 Lift（举起方块）环境，使用 Panda 机械臂
env = suite.make(
    env_name="Lift",
    robots="Panda",
    has_renderer=True,           # 开启可视化窗口
    has_offscreen_renderer=False,
    use_camera_obs=False,
    control_freq=20,
)

obs = env.reset()

for i in range(1000):
    action = np.random.randn(*env.action_spec[0].shape)
    obs, reward, done, info = env.step(action)
    env.render()
    if done:
        obs = env.reset()

env.close()
```

### 2. 机械臂抓取仿真（OSC 控制器）

```python
import robosuite as suite
import numpy as np

# 创建 PickPlace 环境，使用 OSC 操作空间控制器
env = suite.make(
    env_name="PickPlace",
    robots="Panda",
    controller_configs=suite.load_controller_config(default_controller="OSC_POSE"),
    has_renderer=True,
    has_offscreen_renderer=False,
    use_camera_obs=False,
    reward_shaping=True,         # 密集奖励，利于 RL 训练
    control_freq=20,
)

obs = env.reset()
print("观测维度:", obs["robot0_eef_pos"].shape)  # 末端位置
print("动作空间:", env.action_spec)

for i in range(500):
    # action = [dx, dy, dz, droll, dpitch, dyaw, gripper]
    # gripper: -1=张开, 1=关闭
    action = np.zeros(7)
    action[2] = -0.05   # 向下移动
    action[6] = 1.0     # 关闭夹爪

    obs, reward, done, info = env.step(action)
    env.render()

env.close()
```

### 4. 与 Gymnasium 接口集成（用于 RL 训练）

```python
import robosuite as suite
from robosuite.wrappers import GymWrapper
import numpy as np

# 创建环境并包装为 Gym 接口
env = GymWrapper(
    suite.make(
        env_name="Lift",
        robots="Panda",
        controller_configs=suite.load_controller_config(default_controller="OSC_POSE"),
        has_renderer=False,
        has_offscreen_renderer=False,
        use_camera_obs=False,
        reward_shaping=True,
        control_freq=20,
    )
)

# 现在可以像标准 Gym 环境一样使用
obs, info = env.reset()
print("观测空间:", env.observation_space)
print("动作空间:", env.action_space)

for _ in range(100):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()
```

## 常见问题

**Q: 导入 robosuite 报 `ModuleNotFoundError`**
```bash
pip install robosuite
# 或从本地安装
cd robosuite/ && pip install -e .
```

**Q: 渲染窗口无法显示（libGL 错误）**
```bash
sudo apt-get install libgl1-mesa-glx libglu1-mesa
export LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libGL.so.1
```

**Q: 训练速度慢**
- 关闭 `has_renderer=False` 和 `has_offscreen_renderer=False`（不需要图像时）
- 使用 `control_freq=10`（降低控制频率）
- 使用向量化环境：`stable_baselines3.common.vec_env.SubprocVecEnv`

**Q: 如何使用本仓库 `models/menagerie/` 中的机械臂模型**
- robosuite 自带的机械臂模型已足够使用
- 如需自定义，参考 `robosuite/models/robots/` 中的机器人定义方式，仿照 menagerie 的 MJCF 文件接入
